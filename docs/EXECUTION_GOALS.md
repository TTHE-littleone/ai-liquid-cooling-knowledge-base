# AI液冷产业知识库：可执行目标

## 目标

建立一个公开、中文呈现、全球采集且重点覆盖中国与广东的AI液冷产业知识库，用于个人系统学习和数控机床销售相关的业务判断。

## 内容范围

- AI芯片与封装散热、液冷服务器、整机柜和智算中心。
- 冷板式、浸没式、喷淋式；CDU、冷却液、快接、泵阀、换热器、管路与控制。
- 市场规模、产业链、厂商、产品参数、财报、政策标准、项目案例。
- 广东企业、政策、项目、扩产与制造需求专题。
- 液冷零件、制造工艺、机床能力与潜在客户信号。

## 更新节奏

- 每日北京时间约08:07和20:07自动采集公开来源。
- 每周一约07:07发布上一周增量、摘要、预警和邮件。
- 每月首个周一校准市场、厂商和产品参数。
- 每季度审计来源覆盖、失效链接和漏检风险。

GitHub定时任务可能因平台负载延迟。系统记录实际执行时间，不把计划时间当作完成证据。

## 质量规则

- 官方文件、标准和监管披露为A级证据。
- 企业官网为B级证据；厂商性能数据必须标注为厂商口径。
- 权威转引为C级，等待原报告复核。
- 自媒体、转载和营销内容为D级线索，不直接作为确定事实。
- 每条公开结论必须包含来源链接、发布日期或采集日期、地域与证据等级。
- 相互冲突的市场数字并列展示，不强行合并。

## 验收指标

- P0核心来源在线率目标不低于95%。
- 一般新闻入库延迟不超过7天，重大事项争取当天预警。
- 正式知识记录来源可追溯率100%。
- 网站支持学习、检索、筛选、比较、数据下载和周报访问。
- 不绕过登录、验证码、付费墙或robots限制，不转载受保护全文。
- 现金成本为0元；免费服务失效时自动降级并报告缺口。

## 隐私与密钥

网站知识公开并允许搜索引擎收录。邮箱授权码只存放于GitHub Secrets；个人客户跟进、销售评分和商业判断不得进入公开仓库。
